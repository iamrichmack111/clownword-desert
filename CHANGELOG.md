# Changelog

All notable changes to ClownWord Desert are documented here.

## [1.0.0] - 2026-07-30

### Added

- Scrolling 2D desert world rendered with Canvas
- Eight circus tents that spawn clown hordes
- Sight-word spelling combat and tent-sealing mechanics
- Five selectable vocabulary levels
- Combo, heart, minimap, score, particle, and sound systems
- Offline browser support
- GitHub Pages publishing workflow through `publish_to_github.sh`

### Fixed

- Reserved all letter keys for spelling
- Changed movement to arrow keys so words containing W, A, S, or D do not conflict with controls
