# Contributing

Thank you for improving ClownWord Desert.

## Development setup

No dependency installation or build system is required.

```bash
git clone https://github.com/iamrichmack111/clownword-desert.git
cd clownword-desert
python3 -m http.server 8080
```

Open `http://localhost:8080`.

## Before opening a pull request

1. Test movement, spelling, tent sealing, winning, losing, restarting, and sound.
2. Confirm letter keys never trigger movement.
3. Test at least one Chromium browser and Firefox when possible.
4. Keep the game playable without third-party libraries or network access.
5. Update `README.md` and `CHANGELOG.md` for user-visible changes.

## Good contribution areas

- Accessibility
- New educational modes
- Custom word lists
- Mobile controls
- Performance improvements
- Enemy and tent variety
- Classroom features

Please keep pull requests focused and explain the gameplay or educational benefit.
